# VELTOWEB 수정본

## 실행 방법

ZIP을 먼저 압축 해제한 뒤 `veltoweb/index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요 없는 HTML·CSS·JavaScript 사이트입니다.

기존 웹사이트에 적용할 때는 `index.html`, `style.css`, `script.js`, `images` 폴더를 같은 위치에 업로드하세요. 기존 `cafe-de-lune`, `atelier-nove` 상세 사이트 폴더는 유지하세요. 이 수정본은 자동으로 게시되지 않습니다.

## 바뀐 점

- 첫 화면: “우리 브랜드다운 웹사이트. 보기 좋고, 이용하기 쉽게.”로 제작 서비스를 바로 이해할 수 있도록 변경했습니다.
- 영어 메뉴와 설명을 한국어로 정리했습니다. VELTOWEB, Web Design & Development, 두 프로젝트 이름은 유지했습니다.
- 작업 사례 → 제작 서비스 → 진행 과정 → 문의 순서로 구성했습니다. 어려운 표현 대신 메뉴·가격·위치·모바일처럼 구체적인 설명을 사용했습니다.
- 검정·오프화이트 색상, 큰 제목, 얇은 구분선, 넉넉한 여백을 유지했습니다. 포트폴리오는 PC에서 높낮이가 다른 두 열, 모바일에서 한 열로 배치했습니다.
- 원본 포트폴리오 이미지 2장과 공유용 이미지 1장을 그대로 보존했습니다. 샘플·가상 브랜드 표기도 한국어로 유지했습니다.
- 누락된 HTML 닫기 태그와 중복된 반응형 규칙을 정리했습니다.

## 추가한 움직임

- 첫 화면 제목과 설명의 부드러운 등장
- 스크롤에 따른 섹션·작업·서비스·진행 단계 리빌
- 작업 이미지의 작은 확대와 데스크톱에서 최대 8px의 약한 패럴랙스
- 문의 버튼, 링크 화살표, 서비스 행의 호버 전환
- 스크롤에 따른 헤더 높이 변화, 진행 표시선, 현재 메뉴 강조
- 부드러운 페이지 내 이동과 아래로 이동 안내

스크롤을 강제로 제어하는 라이브러리는 사용하지 않았습니다. 휴대폰에서는 패럴랙스를 끄며, 운영체제의 ‘동작 줄이기’ 설정에서는 애니메이션과 부드러운 스크롤을 끕니다. JavaScript가 꺼져도 본문과 링크를 이용할 수 있습니다.

## 포트폴리오와 문의 연결

원본 ZIP에는 포트폴리오 상세 페이지 코드가 포함되어 있지 않습니다. 따라서 상세 페이지를 새로 만들거나 변경하지 않고, 기존 공개 사이트로 연결했습니다. 두 주소는 작업 시 HTTP 200 응답을 확인했습니다.

- https://veltoweb.github.io/cafe-de-lune/index.html
- https://veltoweb.github.io/atelier-nove/index.html

문의는 원본의 인스타그램 계정을 유지했습니다. 메시지 창 연결은 기기의 인스타그램 설치·로그인 상태에 따라 달라질 수 있어 프로필 링크도 함께 제공합니다. 실제 메시지는 발송하지 않았습니다.

다른 도메인으로 이전할 경우 `index.html`의 포트폴리오 주소와 `og:url`, `og:image`를 함께 변경하세요. 기존 공유 이미지의 파일은 그대로 유지했습니다.

## 확인 범위

Windows Edge 브라우저에서 320, 375, 390, 430, 768, 1024, 1440, 1920px 너비로 확인했습니다.

- 가로 넘침, 이미지 로딩, JavaScript 오류, 섹션 표시 확인
- 모바일 메뉴 열기, Escape 닫기, 메뉴 이동, PC 크기로 전환 시 닫기 확인
- 동작 줄이기 및 JavaScript 비활성화 상태의 본문 표시 확인
- PC·모바일 화면 캡처로 여백과 이미지 배치 확인

실제 iPhone·Android 기기 및 Safari에서의 검증은 수행하지 않았습니다.

## 파일 안내

- `index.html`: 문구, 섹션, 링크, 공유 정보
- `style.css`: 색상, 글자, 여백, 반응형, 전환 효과
- `script.js`: 모바일 메뉴, 리빌, 스크롤 상태, 패럴랙스
- `images/`: 원본 프로젝트 이미지와 공유 이미지

외부 폰트나 애니메이션 라이브러리를 새로 불러오지 않습니다. 기기에 설치된 한국어 글꼴을 사용하므로 운영체제별로 글꼴 모양은 조금 다를 수 있습니다.
